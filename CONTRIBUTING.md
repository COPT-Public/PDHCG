# Contributing to PDHCG

Use https://github.com/COPT-Public/PDHCG/issues for bugs and proposed changes, or contact hkl1u@sjtu.edu.cn.
Follow the COIN-OR code of conduct. Include a reproducible example, build details
and a regression test when proposing a numerical or build change. Preserve all
third-party notices. Confirm ownership/licensing permission before contribution.
See tests/README.md for extending the installation tests.
